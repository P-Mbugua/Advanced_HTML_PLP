# Advanced HTML5 Elements & Forms

## Overview
This project demonstrates the implementation of various HTML5 elements, including images, lists, tables, and forms with validation attributes. Additionally, it utilizes local browser storage to save user registration details and dynamically display them in a contact table.

## Features
- **Ordered List**: Displayed using Roman numerals.
- **External Image**: Fetched from [Pexels](https://www.pexels.com/).
- **Contact Table**: Displays user details (Name, Email, Date of Birth) after registration.
- **Registration Form**:
  - Name, Email, Password, and Date fields
  - Dropdown, Radio buttons, and Checkboxes
  - Proper labels and placeholders
  - Validation attributes to ensure data integrity
- **Browser Storage**:
  - Registration details are stored in `localStorage`.
  - Users appear dynamically in the table upon registration.
- **Styling & Effects**:
  - Modern and professional UI using CSS.
  - Hover effects and interactive elements.
  - Mobile-responsive layout.

## Installation
1. Clone the repository or download the files:
   ```sh
   git clone https://github.com/P-Mbugua/Advanced_HTML_PLP.git
   ```
2. Navigate to the project folder:
   ```sh
   cd advanced-html5-forms
   ```
3. Open `index.html` in your preferred browser.

## Usage
1. Open the registration form.
2. Fill in your details and submit the form.
3. Your information will be stored and displayed in the contact table.
4. Refreshing the page retains the stored data.

## Technologies Used
- **HTML5**: Semantic structuring.
- **CSS3**: Styling and responsiveness.
- **JavaScript**: DOM manipulation and local storage handling.
- **FontAwesome**: Icons for better UI experience.
